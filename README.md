# Cisco Packet Tracer Networking Labs

A hands-on networking lab series documenting my journey from
networking fundamentals to advanced Cisco configurations.

## 🚀 About This Repository

This repository contains practical Cisco Packet Tracer labs
that I build, configure, troubleshoot, and verify while
learning networking and cybersecurity.

## 📚 Labs

| Day | Topic | Key Concepts |
|-----|-------|--------------|
| 01 | Static Routing | Routing Tables, Static Routes |
| 02 | EIGRP | Dynamic Routing, Neighbors |
| 03 | OSPF | Link-State Routing |
| 04 | RIP v2 | Distance-Vector Routing |
| 05 | VLSM + RIP v2 | Subnetting, IP Addressing, Routing |
| 06 | VLAN | VLANs, Access Ports |

## 🎯 Learning Goals

- Build strong networking fundamentals
- Practice Cisco IOS configuration
- Improve subnetting and IP addressing
- Understand routing protocols
- Develop troubleshooting skills
- Build practical cybersecurity foundations

## 🛠️ Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 / IPv6
- Networking fundamentals
